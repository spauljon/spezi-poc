# db/ — POC Oracle

Follow the root [CLAUDE.md](../CLAUDE.md) (data rules, isolation, milestone workflow).

- Stack: Oracle Database Free container (own instance, own volume `spezi-poc_oracle_data`), three PDBs: `FHIRPDB` (HAPI), `ANALYTICSPDB` (rollups) and `KEYCLOAKPDB` (Keycloak, M3c).
- Never connect to, modify, or reset the governance project's Oracle. This stack's compose project is `spezi-poc`.
- Credentials live only in gitignored `.env.local` files generated by `make stack-env`; never in committed files, logs, or conversation.
- The analytics project reads HAPI only through the FHIR API, never the FHIR PDB.
- Owner/app split: `*_owner` accounts hold the objects and cannot log in; applications connect as the `hapi`/`analytics` users (CREATE SESSION, DML grants, synonyms). Never give an application user DDL privileges or object ownership.
- Milestones: M1, M3c
- Commit prefix: `db:`
